# AssistCam Saúde — Landing Page (HTML/CSS/JS)

Esta é uma landing page estática baseada no `styleguide-landing-page.md` fornecido. Está implementada apenas com HTML, CSS e JavaScript puro, pronta para ser hospedada no GitHub Pages.

Como publicar no GitHub Pages:

1. Crie um repositório no GitHub ou use um existente.
2. Coloque os arquivos (`index.html`, `styles.css`, `script.js`) na raiz do repositório.
3. Faça commit e envie para a branch `main` (ou `master`).

Comandos rápidos:

```bash
git init
git add .
git commit -m "Landing page AssistCam Saúde"
git branch -M main
git remote add origin <URL_DO_SEU_REPO>
git push -u origin main
```

4. No GitHub vá em *Settings > Pages* e selecione a branch `main` (root). Salve.
5. Após alguns minutos a página estará disponível em `https://<seu-usuario>.github.io/<seu-repo>/`.

Observações:
- Os CTAs da demo são placeholders — em integração real, conecte a um backend ou formulário.
- As fontes utilizam Google Fonts (Inter, Poppins).
